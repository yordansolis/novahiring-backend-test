## Acerca del proyecto

Clínica Salud Valencia S.L. es una clínica privada multiespecialidad en Valencia. Buscamos un/a desarrollador/a full stack para diseñar, desarrollar e implementar desde cero un sistema de gestión de citas médicas que permita a la clínica digitalizar su operación, reducir citas perdidas y mejorar la experiencia tanto del personal como de los pacientes.

El sistema deberá estar operativo  con un plazo maximo de 3 meses.

---

## Responsabilidades principales

- Diseñar la arquitectura del sistema y tomar decisiones técnicas de forma autónoma
- Desarrollar el panel de gestión de citas para el personal de recepción
- Implementar el módulo de reserva de citas online para pacientes
- Integrar la API de WhatsApp Business (Meta) para el envío de recordatorios automáticos
- Sincronizar las agendas médicas con Google Calendar API
- Aplicar las medidas técnicas de protección de datos exigidas por el RGPD y la LOPDGDD para datos de categoría especial (datos de salud)
- Desplegar el sistema en infraestructura cloud y garantizar su disponibilidad en producción
- Comunicar el avance del proyecto de forma periódica al equipo directivo en lenguaje no técnico
- Documentar el sistema para facilitar el mantenimiento y la validación legal posterior
